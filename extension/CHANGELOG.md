# X Search Changelog

## [Keywords] - {PR_MERGE_DATE}

- Find both commands in Raycast by typing tweet or query. Find Advanced Search by typing hashtag.

## [To includes its day] - {PR_MERGE_DATE}

- To now includes posts from that day. The same day in From and To searches that day, instead of finding no posts. The date picker ends on 31 December of this year.

## [Hashtags with commas] - {PR_MERGE_DATE}

- Separate hashtags with commas as well as spaces, as you can for accounts. `#cats,#dogs` searches for either hashtag.

## [Preferred browser] - {PR_MERGE_DATE}

- Choose a Preferred browser in the extension preferences. The list includes every installed application, so pick a web browser. Leave it empty to use your system browser.

## [Results tab per search] - {PR_MERGE_DATE}

- Open an advanced search in any results tab: Top, Latest, People, Media, or Lists. Pick one from Search in in the action panel. The first action opens your preferred tab, and so does Quick Search.
- The Results preference is now called Preferred tab and offers Top or Latest. Default is gone, because X opened Top for it. A saved Default now opens Top.

## [To date] - {PR_MERGE_DATE}

- Let To be 1 January of next year, so a range can include 31 December of this year. X leaves out the To day itself.

## [Draft dates] - {PR_MERGE_DATE}

- Open a saved From or To date on the same calendar day.

## [Engagement counts] - {PR_MERGE_DATE}

- Ask for a whole number when a minimum replies, Likes, or reposts field contains a decimal. Search stays on the form, and that field stays out of the search query.

## [Initial Version] - {PR_MERGE_DATE}

- Open an X advanced search from a form. The results stay on x.com.
- Type a search query in Quick Search and open it on x.com.
